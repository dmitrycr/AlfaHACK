# ADR 0001 Владение данными

Статус: принято пользователем.

Контекст: проект имеет десять прикладных микросервисов. Предложение добавить
одиннадцатый универсальный сервис хранения отклонено.

Решение: один физический PostgreSQL для MVP, отдельные схемы и роли сервисов.
Доступ к данным другого владельца осуществляется через его API или согласованные
события. Общая БД не означает общие таблицы. Kafka служит доставке сообщений.

Следствия: запуск остаётся простым; границы данных можно сохранить при дальнейшем
разделении серверов БД. Распределённые транзакции не применяются. Согласованность
между публикациями, событиями и аналитикой достигается outbox/inbox, версиями и
повторяемой обработкой. Нативный E2E проверяет запрет межсхемного чтения.
